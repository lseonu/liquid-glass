# liquid-glass

Santai design system project implementing Apple Liquid Glass UI/UX patterns.

## Quick Start

- **Design System**: See `resources/liquid-glass-design-system.md` for implementation guide
- **Working Demo**: Open `/home/ubuntu/mockup/` for the live implementation
- **Cheat Sheet**: See `resources/quick-reference.md` for common patterns

## Project Structure

- `resources/` - Design system documentation and reference materials
- `codebases/` - References to implementation codebases
- `history/` - Change documentation (complements git history)
- `notes/` - Scratch space and ideas
